# ממדים קריטיים להתמדה – גלובוס תלת־ממדי

תצוגה אינטראקטיבית של שלושת הממדים (מעורבות, התקדמות, ביצוע) סביב גלובוס תלת־ממדי. כל כרטיס מתהפך מהשאלה לסטטוס שמודד אותה.

- `index.html` – גרסת WebGL (three.js): גלובוס זוהר, כרטיסים בעובי אמיתי, קרני אור ומצגת אוטומטית.
- `carousel.html` – גרסה קלה ב־CSS 3D: קרוסלה סביב גלובוס נקודות.
